# نظام إدارة صالون رنا و جنى (Lumière Beauty Lounge)

نظام متكامل لإدارة الصالون النسائي (المواعيد، الرعبون، الفواتير، ذمم الزبائن، الأرباح، ومساعد الذكاء الاصطناعي) يدعم المزامنة الفورية اللحظية بين الكمبيوتر والهاتف وقابل للتثبيت كتطبيق (Installable PWA).

## نظام المزامنة الفورية بين الأجهزة (Cross-Device Sync)
1. **المزامنة التلقائية اللحظية (Live Polling & Realtime):**
   - يفحص النظام قاعدة بيانات Supabase تلقائياً كل 2.5 ثانية لجلب أي زبونة أو فاتورة أو موعد جديد أُضيف من أي جهاز آخر.
   - فور لمس شاشة الهاتف أو فتح التبويب أو التنقل بين الأقسام (الزبائن، الفواتير، المواعيد)، يتم جلب التعديلات الجديدة فوراً.
2. **زر المزامنة الفورية في الشريط العلوي (🟢 مزامنة فورية 🔄):**
   - يوجد زر أخضر في أعلى الصفحة، بالضغط عليه يتم فحص وجلب أحدث البيانات من السحابة في أجزاء من الثانية.
3. **حفظ مشروط مؤكد (Persist & Sync):**
   - عند الضغط على "حفظ"، لا تُعرض رسالة النجاح إلا بعد تأكيد وصول البيانات لقاعدة بيانات Supabase لضمان عدم ضياع أي إضافة.
4. **منع تعارض البيانات والمسح:**
   - دمج الكيانات الذكي (`mergeStates`) يضمن أن إضافة زبونة من الكمبيوتر وإضافة زبونة من الهاتف تظهران معاً على كلا الجهازين دون أن تلغي إحداهما الأخرى.

## طريقة الرفع والتحديث على GitHub و Vercel
1. استخرجي محتويات هذا الأرشيف واستبدلي بها ملفات المستودع الخاص بكِ على جهازكِ أو ارفعيها مباشرة على صفحة المستودع في GitHub.
2. أو عبر سطر الأوامر (Terminal):
```bash
git add .
git commit -m "Fix cross-device instant sync and mobile updates"
git push origin main
```
3. سيقوم Vercel بالنشر التلقائي خلال ثوانٍ.
4. افتحي الموقع من الكمبيوتر والهاتف وسجلي الدخول بحسابك، وستظهر أي إضافة على الجهازين فوراً.
