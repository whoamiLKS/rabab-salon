# Lumière Beauty Salon — Mobile-Ready & Installable PWA

نظام متكامل لإدارة الصالون النسائي (المواعيد، الرعبون، الفواتير، ذمم الزبائن، الأرباح، ومساعد الذكاء الاصطناعي) متوافق بالكامل مع الهواتف الذكية وقابل للتثبيت كتطبيق (Installable PWA).

## محتويات المشروع للرفع على GitHub
- `index.html`: الكود الكامل للتطبيق.
- `manifest.json`: ملف تعريف تطبيق الويب التقدمي (PWA) للتثبيت على شاشة الموبايل.
- `sw.js`: مشغّل الخدمة (Service Worker) لتفعيل التثبيت والعمل بدون إنترنت (Offline).
- `icon-192.png` & `icon-512.png`: أيقونات التطبيق على شاشة الهاتف.
- `vercel.json`: إعدادات جاهزة للنشر الفوري على Vercel.

## طريقة الرفع على GitHub
```bash
git init
git add .
git commit -m "Initial commit: Lumiere Salon Mobile PWA"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/lumiere-salon.git
git push -u origin main
```
